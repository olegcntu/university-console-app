# University Console App

Spring Boot console application for a university with departments and lectors (completed as a test assignment).

## Features

- `Who is head of department {name}`
- `Show {name} statistics` (assistants, associate professors, professors)
- `Show the average salary for the department {name}`
- `Show count of employee for {name}`
- `Global search by {template}`

## Tech stack

Java, Spring Boot, Spring Data JPA, MySQL, Lombok

## Getting started

Set the MySQL password in `application.properties`, then:

```bash
mvn spring-boot:run
```
